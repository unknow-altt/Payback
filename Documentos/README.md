# PAYBACK v4.2 — Simulador de Hacking Ético

*PAYBACK* es una herramienta de terminal con apariencia agresiva y múltiples módulos de “hacking”, diseñada *exclusivamente para bromas, sustos entre amigos y concienciación sobre seguridad*.  
*Nada de lo que muestra es real.* Todas las IPs, coordenadas, contraseñas y datos son generados aleatoriamente. No realiza ninguna acción maliciosa ni se conecta a internet.

> ⚠️ *ADVERTENCIA LEGAL*  
> Este software es una *simulación inofensiva. El uso de herramientas reales de hacking sin autorización es **ilegal* y puede acarrear graves consecuencias.  

---

## 🎭 Características principales

- *16 módulos* de “ataque” simulados (doxeo, phishing, fuerza bruta, keylogger, botnet…).
- Interfaz en terminal con colores ANSI, barras de carga y efectos visuales intimidantes.
- Generación aleatoria de IPs, MACs, coordenadas GPS, números de teléfono y filtraciones falsas.
- Totalmente *offline*: no envía ni recibe datos reales.
- Escrito en Python 3, compatible con Linux, Windows (PowerShell/Windows Terminal) y macOS.
